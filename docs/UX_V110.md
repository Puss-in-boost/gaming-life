## 保活

GitHub Actions 每天两次执行对 Supabase REST API 的只读请求。公开仓库**不写入任何密钥**，需要到仓库 Settings → Secrets and variables → Actions 配置：
- `GAMING_LIFE_SUPABASE_URL`：该项目 API URL。
- `GAMING_LIFE_SUPABASE_PUBLISHABLE_KEY`：从 Supabase API Keys 复制该项目 publishable/anon 密钥，绝对不是 secret 或 service_role。

配置后手动运行 `Gaming Life Supabase keepalive` workflow，确认 HTTP 请求成功。注意：read-only API 请求能够验证可用性，但 Supabase 是否将其作为避免休眠的足量数据库活动无法保证；定时任务也可能因 GitHub Actions 规则暂停或延迟。**在验证数据库活动计数前不应宣称已实现可靠保活。** 在项目暂停状态下无法自动恢复。

运行 `node tests/v17.test.mjs && node tests/v18.test.mjs && node tests/v19.test.mjs && node tests/v110.test.mjs`。
