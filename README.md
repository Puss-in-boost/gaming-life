# Gaming Life · 游戏人生 V1.4

**Gaming Life 是独立的现实人生 RPG。** 以真实成果推进主线，以任务进度减少「没做完等于白做」的挫败感，以经验、奖励币和体验奖励强化正反馈。未来 Life OS 可作为人物面板逐步整合。

## 使用

打开 <https://puss-in-boost.github.io/gaming-life/>（合并本 PR 并成功部署后为 V1.4）。

1. **优先主线与并行主线。** 今日页面显示一项优先主线；如果有另一项活跃主线，会同时显示为「备用战线」，一键可切换优先级。无需一天完成两条主线。
2. **先记录进度，达标后再领完整奖励。** 点击任务卡的「✎ 更新进度」，在「未开始 / 进行中 / 待确认」之间选择，可补充最多240字进展。记录进度**不发放 XP 或奖励币**；真正完成后点「✓ 完成任务」才会结算。
3. **求职主线快捷领取。** 首页「🎯 领取求职冲刺主线」提供四项任务：简历最终核对、八个岗位清单、首批三份真实投递、后续每周五份投递。先预览再确认；已有任务与记录不会删除。与之前聊天分享的 `career-applications-202610` 任务包 ID 相同，重复导入不会重复创建。
4. **毕业主线保留。** 从求职任务包切换优先级时，当前的论文/送审主线仍会保留在并行战线。任务可反复切换优先级。
5. **与 ChatGPT 的任务大厅闭环。** 在首页点击「复制当前状态」，得到两条主线、已记录的进度说明、最近进度足迹、奖励余额和任务完成摘要。**只有你自己点击复制并发送，才会离开本机。发送前请检查笔记中是否有私人信息。**
6. **查看日志与奖励。** 「日志」新增近期「进度足迹」。奖励所保持 V1.3 的 XP、奖励币独立和月度预算机制；休息、吃饭和普通娱乐不需要兑换许可。

## 数据兼容与保存

- **继续使用** `gaming-life-v1-local`，原任务、经验 XP、金币、兑换历史、成就不清零。
- 新字段 `questProgress` 和 `progressHistory` 在旧记录中不存在时会自动补齐；记录并包含在「设置 → 导出 JSON 备份」中。
- 一次性任务的进度跨日保留；每天/每周重复任务的进度按对应日期/周独立记录，下一周期自动显示「未开始」，但历史进度仍在日志中。
- 「待确认」表示用户自己待核对或等待实际反馈，**不会自动审核**，也不意味着现实任务已经完成。
- 状态切换不会凭空发放奖励。任务完成仍沿用历史防重复结算和撤销时金币余额检查。
- 数据仍在浏览器 `localStorage`；**尚无云端同步**。建议定期导出 JSON 备份，清除浏览器站点数据可能丢失进度。
