# Gaming Life · 游戏人生 V1.3

**Gaming Life 是主产品；Life OS 未来作为人物面板纳入，不在本次修改里整合。** 把现实中的有效行动变成主线、支线、升级、冒险币、成就与真实奖励体验。

## 网页

<https://puss-in-boost.github.io/gaming-life/> （本 PR 合并并部署后生效）。静态 GitHub Pages 页面，不依赖付费 API。

## 这版怎么用

1. 首页点 **「✨ 领取本期推荐任务」**，预览任务包并确认后，你会得到适合毕业阶段的一个主线和自选支线；已有任务/历史成绩不删除。以后可以用 ChatGPT 生成新的任务包。
2. 完成任务，获得 **XP + 奖励币**。XP 用于升级；奖励币用于兑换体验。奖励币不等于人民币。
3. 到 **「🎁 奖励」** 页面，先看免费体验、永久称号等零消费奖励；如需吃点喜欢的东西或简单娱乐，预算需要同时足够。
4. **月度额外奖励预算默认设为 ¥30**（保守示例，不是消费建议），可以自行改成 ¥0–300。奖励兑换只是预留预算，不会从银行卡或账本付款；未享用的奖励取消后退币和预算预留。
5. 兑换后在「奖励背包」里点击 **「已享受」**，让奖励形成真实而不只是数字的生活体验。
6. 任务计划变化时，在首页「复制当前状态」发送给 ChatGPT；更新任务包只在你预览确认后保存。

## 个人化经济规则

| 行动 | XP | 冒险币 |
|---|---:|---:|
| 论文/送审的一处实际成果 | 50 | 25 |
| 按计划训练或恢复 | 20 | 10 |
| 知识学习并复述 | 20 | 10 |
| 提早开始睡前准备 | 15 | 8 |
| 财务复盘、自然的社交或探索 | 15 | 8 |

- 普通任务金币每日最多 60、每周最多 180；经验 XP 仍会如实记录。阶段 BOSS 的一次性奖励另算。
- 默认 **1 主线 + 最多 2 支线**；不奖励为了刷分加练、熬夜、无意义拆分工作。
- 自定义任务/ChatGPT 任务包支持独立设置 `coins`，但受普通任务每日/每周上限约束。
- 免费体验与虚拟奖励优先；衣鞋、数码设备与长途旅行属于未来愿望清单，不预设购买资格。
- 基础休息、日常饮食和娱乐本来就是生活的一部分，不需要兑换才可进行。

## 与旧存档的关系

- 保持 `gaming-life-v1-local` 存储键，**旧任务、XP、日志与兑换记录保留**。
- 第一次从 V1.2 升级，会把旧版「累计 XP - 已兑换金币」冻结为 *旧版剩余奖励币*，之后新增的行动按新经济规则发币；不能重复领取旧任务的币。旧兑换会保留为已兑换历史，不会重复扣款。
- 对于老玩家，自动更新首页商店并不会删除原有自定义奖励；新默认奖励会追加到商品列表。任务库只在你主动点击「领取本期推荐任务」并确认后追加个性化任务。
- 浏览器本地数据仍会因清理站点存储而丢失。请使用「设置 → 导出 JSON 备份」；跨设备同步、IndexedDB、Supabase 尚未实现。

## 隐私 / 未来路线

- 默认所有私人成长记录只在本地，仓库与 GitHub Pages 仅托管代码；不自动上传任务或聊天内容。
- 游戏内关键词识别是本地规则，需要用户确认，不是真正的 AI 服务。
- 有效性优先于复杂度：后续再逐步增加装备、技能树、按任务状态生成奖励及本地优先的 Supabase 同步。
