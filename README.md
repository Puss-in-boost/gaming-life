# Gaming Life · 游戏人生

**游戏人生是独立产品，人生管理是角色成长的一部分。** 将长期的人生目标变为每日主线、可选支线、章节 BOSS、经验等级和成长日志。未来原 Life-OS 的任务、运动、财务、睡眠、学习等能力将作为 **「人物面板」** 整合进 Gaming Life，而不是以 Life-OS 作为游戏容器。

## 立即运行

- 双击 `index.html` 即可在桌面浏览器打开（`file://` 模式）。
- 或在本目录运行 `python -m http.server 8000`，访问 <http://localhost:8000>。
- **部署：** 新建单独的 GitHub 仓库 `gaming-life`，将本文件夹的内容上传至仓库根目录，设置 Pages 来源为 **GitHub Actions**。此仓库已包含 `.github/workflows/pages.yml`。
- 预期线上地址：`https://<GitHub用户名>.github.io/gaming-life/`，以 GitHub Pages 实际部署地址为准。

## 使用

1. 「今日」选择并完成一个主线任务，支线可选（最多两项）。
2. 完成任务会自动更新 XP，误操作可以撤销。
3. 在「旅程」手动确认现实中的阶段性里程碑，在「日志」查看记录。
4. 「设置」可创建任务、启停任务、导出或导入 JSON 备份。
5. 输入一句话可触发本地关键词匹配，**必须由用户确认**才计入 XP；目前不是 AI。

## 本地数据与隐私

- V1 使用当前浏览器的 `localStorage`，存储键为 `gaming-life-v1-local`。任务、记录、日志都保存在本机；**尚未接入 Supabase，不跨设备同步**。
- 使用不同设备、不同浏览器，或清理站点数据，可能丢失本地记录。请使用「设置 → 导出 JSON 备份」。
- 从旧版 Life RPG 迁移：先在旧站「设置 → 导出 JSON 备份」，然后在 Gaming Life 里「导入备份」。新旧存储键不同，不会无意写入原有 Life-OS 数据。
- 网页静态资源在 HTTPS 下首次成功加载后可被 Service Worker 缓存以方便离线再次打开；已加载的页面可在断网时记录任务。**浏览器数据仍不是可靠备份**。
- 暂无登录功能。GitHub 仓库只存放应用代码，不上传个人任务数据，除非用户自行提交个人 JSON 备份（请勿这样做）。

## 产品结构

| 模块 | 说明 | V1 状态 |
| --- | --- | --- |
| 冒险大厅 | 今日主线、支线、奖励、经验条 | 已有 |
| 冒险地图 | 阶段目标与里程碑 | 基础版 |
| 冒险日志 | 完成历史、一句话记录 | 基础版 |
| 人物面板（原 Life OS） | 技能、身体、财务、工作与生活仪表盘 | 规划中，尚未整合 |
| 账号与同步 | IndexedDB 本地优先 + 独立 Supabase 数据同步 | 规划中，尚未实现 |

有关未来数据模型、安全与合并边界：见 [架构说明](docs/ARCHITECTURE.md)。

## 本版本边界

- 不依赖 Node/npm、服务器、数据库、AI API 或付费服务。
- XP 是游戏反馈，不是实力分数；没有惩罚式连续签到。
- V1 不会自动解析论文文件、不具有真实 AI 任务生成能力。
- `Life-OS` 仓库仍然保留，不在本次迁移中删除、覆盖、修改它的主应用。
